Agnes 生图 MCP 连接器 mcp_agnes v1.1.0 —— 使用说明
====================================================

一、这是什么
  把本机的 Agnes 网关（agnes2api，127.0.0.1:7871）包装成一个 **MCP 服务**，
  让支持 MCP 的客户端（DeepSeek Harness、Claude Desktop、Cline……）直接调用
  「出图 / 列出生成记录 / 查网关状态 / 删记录」四件事。
  它自己不生成图片，只是把客户端的请求转给本机网关，所以**网关必须先跑起来**。

二、目录里有什么
  mcp_agnes.exe     连接器本体（stdio 传输，由客户端拉起，不要双击）
  _internal\        程序依赖，勿删勿移
  使用说明.txt      本文件

三、前置条件
  1. 网关已启动：双击 agnes2api.exe（本包解压目录里那个），
     浏览器能打开 http://127.0.0.1:7871/health 看到 {"ok": true, ...}。
  2. 连接器要能读到网关的 config.json（里面有 admin_token）。
     查找顺序：--config 参数 → 环境变量 AGNES_CONFIG → exe 同目录 → exe 上一级 → 当前目录。
     装在别处就读不到，用环境变量指定：
        setx AGNES_CONFIG "<解压目录>\config.json"
     网关地址不是 7871 时：setx AGNES_BASE "http://127.0.0.1:7900"

四、接进 DeepSeek Harness（DSH）
  编辑 %USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml，在**文件末尾**追加
  （注意 `- insert:` 是新增条目的唯一写法，Windows 路径用单引号）：

  # --- Agnes 生图 MCP ---
  - insert:
      - id: mcp-agnes
        name: '@deepseek-ai/dsh-mcp-client'
        config:
          serverName: agnes
          transport: stdio
          command: 'D:/APP/agnes2api/mcp/mcp_agnes.exe'
          env:
            PYTHONUTF8: '1'
            PYTHONIOENCODING: 'utf-8'
          toolCallTimeoutMs: 300000
          failOnStartupError: false

  保存后**不用重启**（实测 10 秒内自动拉起新进程）。工具名形如
  mcp__agnes__generate_image。第一次接入如果 DSH 里没出现工具，重启一次 DSH 再看。

五、接进其它 MCP 客户端（Claude Desktop / Cline 等）
  在各自的 mcpServers 配置里写：

  "agnes": {
    "command": "D:/APP/agnes2api/mcp/mcp_agnes.exe",
    "env": { "PYTHONUTF8": "1", "PYTHONIOENCODING": "utf-8" }
  }

六、四个工具
  generate_image(prompt, size?, model?, show?)
      出一张图，存进网关的 gallery\，返回路径 / 尺寸 / 体积 / 耗时；
      size 如 1024x1024 或 2K，model 默认 agnes-image-2.5-flash。
      show=true（默认）时还会把图片本身回给客户端，前提是模型支持收图。
  list_images(limit?)
      列出最近的生成记录（默认 10 条）：时间、提示词、尺寸、体积、耗时。
  gateway_status()
      网关版本、地址、账号数、各号状态、累计用量。
  delete_image(id)
      删一条记录（连磁盘文件一起删）。

七、注意
  * 每次出图要 10~80 秒，客户端那边超时设长一点（DSH 默认 60 秒，本包建议 300 秒，
    上面配置里的 toolCallTimeoutMs 就是干这个的）。
  * 连接器的日志全走 stderr，不会污染 MCP 协议通道；客户端一般能在
    「服务器日志」里看到 [mcp-agnes] 开头的行。
  * 端口 7871 被占用或网关没起：工具调用会返回「连不上网关」，
    先确认 http://127.0.0.1:7871/health。
  * 本包是**文件夹版**（onedir）：单文件 exe 在本机会报
    [PYI-ERROR] Could not create temporary directory!，原因见网关那边同款说明。
